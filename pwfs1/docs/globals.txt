		Gemini A&G WAVEFRONT PROCESSING SYSTEM
		======================================

		Global variables and shared memory access
		=========================================

Most of the communication between tasks in the AGWPS takes place through
messages sent along pipes. However, there are some global variables and data
structures used as central repository of information, and these are listed
here.
